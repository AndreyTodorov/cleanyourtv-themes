  1. Save the file
    Make a folder for your theme, for example my-theme, and save the config.json text in it as config.json. A background picture goes beside it as wallpaper.jpg: 1920×1080, dark, under about 300 KB.
    2. 
            
  2. Send it to the TV
    With ADB on and the cleanyourtv repo on your computer, run this from the repo folder. Home restarts with the theme.
    
              
    TV_HOST=<tv ip> tools/theme.sh path/to/my-theme
    
              
    On Windows:
    
              
    powershell -ExecutionPolicy Bypass -File tools\theme.ps1 -TvHost <tv ip> path\to\my-theme
    3. 
            
  3. Go back any time
    This returns the launcher to its built-in look.
    TV_HOST=<tv ip> tools/theme.sh --reset
    4. 
          

          
Not in the studio, because a theme can't set them: icon_tiles, settings_fallback_components, settings_key_scancodes, latitude and longitude live in the launcher's config.xml and need a rebuild. race_calendar is written by tools/race_calendar.py. Want your theme in the project? Read Create a theme: it needs a screenshot from a real TV.
